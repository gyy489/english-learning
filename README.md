# 每日英语

这是我为自己学习英语开发的一个小工具。

它不是商业产品，也不是通用的英语学习平台。里面的功能、内容和学习节奏都围绕我自己的习惯设计，并会随着我的学习过程继续调整。目前的目标是把英语水平提升到雅思 6.5 左右。

我的本地雅思资料库包含 **272 篇阅读材料**（P1 79 篇、P2 93 篇、P3 100 篇），以及《剑桥雅思 1》的 **4 套完整听力试题**（共 16 个 Section）。为避免公开分发原始试题，这些题库文件不会提交到 GitHub。

当前版本的每日生成流程使用 16 个听力 Section 作为情境素材；272 篇阅读材料已经完成 Markdown 转换和索引，保留在本地资料库中，但暂未接入当前生成流程。

每天生成练习时，程序会选择一个近期没有使用过的试题片段，再结合我前一天记录的生词和已经到期的复习词，生成一篇适合当前水平的新文章，同时配套中译英练习和听力音频。没有掌握的词会继续出现在新的语境中，新词数量则受到控制，让我在不过载的情况下每天稳定扩大词汇量。

## 它能做什么

- 结合雅思试题、前一天的生词和历史复习记录生成每日英语短文
- 用 1、3、7、14、30、60 天的间隔安排单词复习
- 在本地网页中阅读文章、查询词义和标记生词
- 生成中译英练习，保存草稿和订正记录
- 把文章生成适合跟读的英语听力音频
- 将文章、词库和学习记录保存在本地 Markdown/JSON 文件中

## 使用

只阅读现有内容时，在项目根目录运行：

```bash
python3 english-learning-web/server.py
```

然后访问 <http://127.0.0.1:8787>。

如需生成文章或音频，请先配置 `OPENAI_API_KEY`，再运行：

```bash
uv run --with openai python english-learning-web/server.py
```

环境变量示例见 `.env.example`。更完整的 Web 应用说明见 [`english-learning-web/README.md`](english-learning-web/README.md)。

## 主要目录

- `english-learning-web/`：本地 Web 应用
- `作文素材/按时间排序/`：每日文章、写作练习与听力音频
- `作文素材/单词复习/`：词库、复习策略和历史记录
- `scripts/`：音频生成、词表构建和检查脚本
- `skills/ielts-daily-article/`：每日内容生成规则
- `tests/`：自动化测试
